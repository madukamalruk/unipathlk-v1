# Demo video notes

This is a captioned walkthrough assembled from captured local application views. It is not a continuous screen recording. It has no audio.

Only the nine supplied CUA captures under local-setup/demo-captures were used. Screens were scaled and letterboxed with explanatory text; no generated app screens or fabricated cursor actions were added.

Activity caption mode: **live**. The source filename 03-live-ai-activity.jpg is not itself evidence of live AI. The caption follows the visually reviewed replacement capture, which reports AI-assisted planning.

The real catalogue is a 31-programme, 12-field discovery sample. Real complete costs, admission/intake and professional recognition remain subject to confirmation. The LKR 54,000 / zero-gap and LKR 84,000 / LKR 22,000-gap scenes are explicitly fictional test examples, not real fees, programmes or transfer offers.
